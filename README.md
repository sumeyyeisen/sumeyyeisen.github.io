<h1 align="center">
  Sümeyye İsen - Portfolyo Sitesi
</h1>
<p align="center">
  <a href="https://www.gatsbyjs.com/" target="_blank">Gatsby</a> ile geliştirilmiş kişisel portfolyo sitem.
</p>

Bu proje, <a href="https://github.com/bchiang7/v4" target="_blank">Brittany Chiang'ın v4 portfolyo şablonu</a> (MIT lisanslı) temel alınarak geliştirilmiştir.

## Kurulum

```bash
npm install
npm run develop
```

Site `http://localhost:8000` adresinde açılır.

## Build

```bash
npm run build
```

## İçerik

- `src/config.js` — sosyal medya linkleri, navigasyon menüsü ve renk ayarları
- `content/jobs/` — deneyim/iş bölümü
- `content/projects/` — projeler bölümü
- `content/featured/` — öne çıkan projeler
- `content/posts/` — blog yazıları (opsiyonel)

## Lisans

MIT — orijinal şablon Brittany Chiang'a (2018) aittir, bu proje o lisans koşulları altında değiştirilerek kullanılmıştır.
